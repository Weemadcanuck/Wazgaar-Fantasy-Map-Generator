# Obsidian Fork 1.154.6

Windows x64 baseline for the Obsidian Fork, before deeper Archive integration.

- **Obsidian export:** linked Markdown reference notes, keeping generated map data separate from authored lore.
- **Custom point layers:** editable locations beyond the built-in map categories.
- **Relief and coasts:** reusable raster tiles for distant views; full-detail vectors retained for editing and export. Cold loading can still stutter.
- **Tools:** collapsible sections to keep the panel manageable.
- **Terminology:** polities and settlements restored throughout the interface.
- **Fullscreen:** fixes rough text and edges on the tested Windows/NVIDIA setup. GPU acceleration stays enabled.

Download and run **azgaar-obsidian-fork-1.154.6-win-x64.exe**. Close the app before installing. Updates are manual; checksums are in `SHA256SUMS.txt`.

Obsidian export is one-way. This is the baseline for the separate Archival Fork, not bidirectional vault synchronization. Keep copies of older maps: new saves cannot be reopened in the pre-1.154 Obsidian edition.

Manually tested, including fullscreen focus changes and pan/zoom. Application, desktop and script tests pass.
